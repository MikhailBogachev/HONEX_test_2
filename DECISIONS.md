# DECISIONS.md — Архитектурные решения

## 1. Стратегия доступа: Playwright-only

**Решение:** Playwright + playwright-stealth, headless=False.

**Обоснование:**
- Avito блокирует прямые HTTP-запросы (403/429) — requests не получает данных
- Мобильное API (`m.avito.ru/api/...`) нестабильно: ключ и эндпоинты меняются без предупреждения
- Playwright исполняет JavaScript, получает полноценный DOM с data-marker селекторами
- headless=False детектируется реже, чем headless=True
- playwright-stealth скрывает `navigator.webdriver`, подменяет WebGL-отпечатки

**Fallback:** При CAPTCHA — остановка и ручное решение в видимом окне браузера.
Это соответствует ТЗ: «Допускается однократное ручное подтверждение».

## 2. Селекторы: data-marker

**Решение:** Использовать только `data-marker` атрибуты, не CSS-классы.

**Обоснование:**
- CSS-классы на Avito меняются каждые 1–2 недели
- `data-marker` стабильны: обновления раз в 1–3 месяца
- Avito использует их для внутренней разметки и тестирования

## 3. Seller Identity

**Решение:** Двухэтапное извлечение данных продавца.

1. **Превью** (из карточки/listing): `seller_name`, `seller_id`, `seller_profile_url`, `seller_type` — через `data-marker="seller-info/..."`
2. **Enrichment** (профиль): полные 11 полей — через отдельную навигацию на `seller_profile_url`

**Извлечение seller_id** (вынесено в [`parsers/seller_utils.py`](src/parsers/seller_utils.py)):
- Из карточки/listing: hex-32 из пути URL `/user/<hex32>` → `extract_seller_id_from_path()`
- Из профиля продавца: hex-32 из query-параметра `?sellerId=` → `extract_seller_id_from_query()`

**Защита от ошибок identity:**
- Seller enrich привязан к конкретному объявлению
- Seller ID извлекается только из URL профиля (не из соседних блоков)
- Нельзя смешивать данные разных продавцов

## 4. Кеширование профилей (Seller Cache)

**Решение:** Run-scoped cache с ключом `seller_id` или `seller_profile_url`.

**Реализация:**
- `asyncio.Lock()` на каждый ключ — защита от concurrent in-flight запросов
- Double-check locking: первый запрос побеждает, остальные получают кешированный результат
- Кеш живёт в рамках одного запуска (не сохраняется между запусками)
- Один профиль загружается **не более одного раза** за запуск (требование ТЗ)

## 5. Фильтры

### OEM-артикул
- Нормализация: upper + удаление пробелов/дефисов/разделителей
- Точное совпадение в title + description + params
- Не принимать аналоги с другим OEM

### Состояние «Новое»
- Приоритет: `params` → `title` → `description`
- Явное `Б/у` → reject
- Отсутствие информации → reject (консервативный подход)

### Регион «Москва и МО»
- Набор паттернов для Москвы и городов МО (Подольск, Балашиха, Химки и др.)
- Проверка `address` и `city` полей
- **НЕ** используется опасная проверка `"мо" in text` (ТЗ запрещает)

### Цена > 0
- Проверка `price` > 0
- `None` и 0 → reject

## 6. Антибан

| Механизм | Параметр |
|----------|----------|
| Stealth-плагин | `playwright-stealth` |
| Random delay | 2–4 сек между запросами |
| Scroll emulation | 3 скролла перед парсингом |
| CAPTCHA detection | Проверка URL и DOM на наличие капчи |
| Persistent session | Сохранение cookies между запросами |

## 7. Данные и форматы

- **CSV, JSON, XLSX** — три формата с одинаковой схемой
- **XLSX** — два листа: `Listings` + `Run summary`
- Seller-поля плоские (flatten) в строке объявления
- Неизвестные значения → `null`, не `0`
- `params` → строка через `"; "`

## 8. Зависимости и секреты

- **Нет платных сервисов** — только open-source библиотеки
- Cookies и токены **не сохраняются** в репозитории, логах, CSV/JSON/XLSX
- Секреты (если нужны) только через `.env` (в `.gitignore`)
- URL allowlist проверяется перед **каждым** запросом

## 9. Ограничения и риски

| Риск | Митигация |
|------|-----------|
| Avito изменил data-marker | Обновить селекторы в `parsers/card_parser.py` / `parsers/listing_parser.py` |
| CAPTCHA на каждом запросе | Ручное решение, затем продолжение |
| Изменилась структура профиля | Обновить `parsers/seller_parser.py`, fallback на partial |
| Блокировка IP | Использовать прокси (раскрыть в DECISIONS.md) |
| headless=True перестал работать | Переключиться на headless=False |
